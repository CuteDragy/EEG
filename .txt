# EEG 数据工程师实习工作台

1. 常用开发命令：
运行你的代码：python 你的文件名.py （例如：python test_run.py）
安装新工具箱（必须在带 eeg_env 标志时运行）：pip install <包名>
2. 注意事项：
- **保存**：编写代码时请经常保存文件（`Ctrl+S`）。
- **虚拟环境**：始终在激活 `eeg_env` 后安装包或运行脚本：
   - PowerShell（推荐）：`& .\eeg_env\Scripts\Activate.ps1`
   - CMD：`.\eeg_env\Scripts\activate`
- **依赖管理**：安装新包后更新依赖清单：`pip freeze > requirements.txt`；避免在全局环境中直接安装包。
- **测试优先**：在提交代码前运行 `pytest`，确保关键功能通过测试。
- **提交信息**：使用简洁明确的 commit message（例如：`feat: add preprocessing` / `fix: correct channel index`）。
- **不要提交敏感信息**：不要将密码、API Key、或包含个人信息的数据文件提交到 git（使用 `.gitignore`）。
- **数据隐私与合规**：处理 EEG 或个人数据时请确保已进行脱敏并有合法使用权限，遵守相关法规与机构要求。
- **大文件处理**：对于大于 100MB 的文件，使用 Git LFS 或外部对象存储，不要直接加入仓库。
- **Python 版本一致性**：在项目中记录并保持一致的 Python 版本（例如 `3.10`），以利于依赖兼容与结果复现。
- **代码风格与静态检查**：推荐在提交前运行 `black .`、`isort .`、`flake8 .`，保持代码风格一致并及早发现问题。
- **重现性**：记录数据来源、处理步骤与随机种子（例如 `numpy.random.seed()`），保证结果可复现。
- **Windows PowerShell 权限**：如遇执行策略限制，可在管理员模式下运行：
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`，操作前请确认安全性。

抑郁症现在依旧是一个主流精神健康疾病，影响了很多人，甚至有一定的死亡率，所以对于这类疾病来说，应该尽早诊断和治疗，要准确诊断出这种疾病，而传统的诊断工具相对比较落后，容易出现偏差和误诊，所以这样的局面一直无法解决，抑郁症依旧很严重，在研究之下，现在有了新的诊断和评估方式，那就是用生物标志物，这种全新疗法似乎与传统治疗相比更加管用，而脑电图（eeg）可以提取出一些特定指标，作为生物标志物，这些标志物可能有助于抑郁症的诊断和治疗，而且拥有比传统方法更好的准确度，所以脑电图（eeg）在现在有很强的实用性，关于它的研究也越来越多


脑电图（EEG）和心电图（ECG）都是通过在身体表面粘贴电极来捕捉生物电信号，在如今人工智能普及的情况下，使用机器学习算法可以对它们进行精准分类，比如脑电波比率 Theta/Alpha（TAR），在训练模型之下有了很高的准确率，再比如说，可以通过建立一个多模态框架来对它们的表现进行评估，算法模型，多模态的应用可以改善对它们的分类。


收集了约 211 名受试者的数据，进行了数据处理与分析，将 EEG 信号按照固定的时间间隔，分割成重叠（连续）和非重叠（非连续）的片段，随后运用时域分析，提取到了特征参数，当采用非重叠分割技术并结合 K-最近邻（KNN）分类器时，该算法模型表现最为优异。这一组合成功实现了高达 96.32% 的分类准确率，取得了最佳的压力检测与分类效果，是脑电图进行压力分析的一个典型案例。
